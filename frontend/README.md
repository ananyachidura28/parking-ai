# ParkSmart AI - Frontend React Client

Enterprise Smart Parking Management Client built with React, Vite, Tailwind CSS, Zustand, Framer Motion, Recharts, Leaflet Maps, and Socket.IO Client.

---

## 💻 Tech Stack

- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS + Glassmorphism + Dark/Light Theme
- **State Management**: Zustand
- **Real-Time Client**: Socket.IO Client
- **Maps & Charts**: React-Leaflet, Recharts
- **Animations**: Framer Motion, Canvas Confetti
- **Icons**: Lucide React

---

## 🛠️ Installation & Setup

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Environment Variables**:
   Create `.env` inside `frontend/`:
   ```env
   VITE_API_URL=http://localhost:5001/api
   VITE_SOCKET_URL=http://localhost:5001
   ```

3. **Run Development Server**:
   ```bash
   npm run dev
   ```

4. **Production Build**:
   ```bash
   npm run build
   ```
